### About

I'm an **Applied AI Engineer** building intelligent systems, developer tools, and software products that solve real problems.

My background combines **engineering, product thinking, and business operations**. I'm interested in what happens when AI moves beyond a prototype: how systems integrate with existing infrastructure, how agents behave under failure, and how we verify that something actually works.

I work from understanding a problem and designing its architecture to implementation, integration, testing, and evaluation.

**Building something is only half the challenge. Proving it works is the other half.**

### Engineering in progress

- **[Open VS Code Agent](https://github.com/RaulMermans/Open_VS_Code)** — Local-first coding-agent desktop environment built around open-weight models, governed tool execution, and reproducible evaluation. A documented 24-task read-only benchmark improved from 37.5% to 75%; real-world desktop acceptance remains in progress.
- **[IRIS OS](https://github.com/RaulMermans/IRIS-OS)** — Personal AI operating system exploring specialist-agent orchestration, memory, context, and governed execution. Public repository is an architecture edition.
- **[HALO Control](https://github.com/RaulMermans/AMD-HALO-Control)** — Local AI infrastructure for routing, model management, workload governance, and resource observability. Public architecture edition; runtime acceptance is incomplete.
- **AAO / Applied AI Operations** — Private reusable foundation for governed AI workflows, approvals, execution controls, and integrations.
